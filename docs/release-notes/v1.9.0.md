# Gloam 1.9.0

This release fixes night-mode scheduling, calibration setup, saved reports, and history handling.

- Night-mode pauses now take precedence over manual overrides and expire correctly.
- The circadian dose governor preserves settings that already meet the ceiling, invalidates cached results when measured spectra change, and handles temperature and brightness boundaries more accurately. This can change applied night-mode output when dose limiting is enabled.
- Calibration reports preserve custom targets and color coordinates when saved and reopened. Reports created close together no longer overwrite each other.
- Instrument detection supports cancellation, prevents overlapping attempts, and recovers after failures. Canceling verification during the final measurement no longer reports success.
- Settings migration preserves supported fields and protects newer or malformed settings files. Shared atomic persistence avoids temporary-file collisions and rejects oversized files before replacing saved data.
- Binary LUT loading rejects malformed payloads before allocating the LUT; serialization uses less memory.
- Dose history handles UTC queries around local midnight and uses calendar filenames independent of regional settings. Trust Check histories no longer collide between monitor IDs, retain access to older records, and compare drift in timestamp order.
- Game discovery cancellation and report-history selection are more reliable.

Validation: strict Release build with zero warnings or errors and all 1,339 tests passing. Regression coverage includes color serialization, governor boundaries, cancellation, persistence, and history isolation. No fresh hardware-and-meter validation was performed; night-mode output changes are covered by automated tests, not new physical measurements.
