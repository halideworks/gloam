# Gloam 1.9.2

Calibration no longer fails at instrument startup with "Failed to locate display type matching 'o'" (issue #7).

- The spotread display-type selector (`-y`) is now taken from the table spotread prints for the connected instrument instead of a fixed letter per display type. ArgyllCMS only lists the technology letters (`o` OLED, `e` white LED, `b` RGB LED, `m` plasma, `p` projector) when matching X-Rite EDR corrections have been imported, which a fresh install never has. On a clean install the i1 Display Pro family accepts only `n|l` (Non-Refresh), `r|c` (Refresh) and a built-in CCFL row, so OLED, LCD LED and wide-gamut LCD all failed there.
- OLED, LCD LED and wide-gamut LCD now resolve to the instrument's Non-Refresh base calibration when no matching correction is installed; CRT, plasma and projector resolve to the Refresh base. When a matching EDR row exists, the same letters as before are used. One measured-output change: on a clean i1D3, CCFL LCD now uses the built-in "LCD CCFL PVA" spectral row (`-y 1`) instead of the Non-Refresh base it reached through `-y l` before, because it is the only CCFL row listed. If you calibrated a CCFL display with 1.9.1, re-run the calibration. When a `.ccss` meter correction is selected, it continues to supply both the spectral calibration and the refresh mode, as spotread already did.
- If spotread still rejects the selector, Gloam reads the table spotread prints on the way out and restarts once with a selector from that table. The failure message now lists the selectors the instrument accepts.
- With two meters connected, only the rows spotread printed for the meter Gloam opened are considered.
- The calibration setup screen now shows which calibration row the meter will use for the selected display type, and warns when the meter has no correction for that type and no CCSS/CCMX file is chosen.

Validation: all 1,388 tests pass and the strict Release build has zero warnings or errors. The rejection and retry path was exercised against an i1 Display Pro on Argyll 3.5.0 by forcing an invalid selector; the retry restarted with a listed selector and reached the ready prompt. The reporter's clean-install table and a table with imported EDR rows are pinned as test fixtures.
