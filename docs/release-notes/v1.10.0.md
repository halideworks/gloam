# Gloam 1.10.0

- SDR calibration now ACTUALLY reaches the display. Gloam used to register SDR profiles only where Windows ignores calibration data, so verification measured the uncorrected panel. If your most recent Gloam calibration was in SDR, Gloam re-applies it the next time the display is in SDR. For an older calibration of the other mode, switch the display to that mode and activate it once in Profile Manager; Gloam swaps it in from then on.
- SDR calibration applies only while **Automatically manage color for apps** is on (Settings > System > Display). Gloam tells you after installing if it's off. Keep measuring with it off, then turn it on.
- SDR and HDR calibrations are now kept separately. Windows has room for one calibration per display, so Gloam swaps in the right one whenever you turn HDR on or off. When you switch to a mode with no Gloam calibration, or deactivate one in Profile Manager, the advanced color profile Gloam replaced comes back (for profiles replaced by 1.10 or later).
