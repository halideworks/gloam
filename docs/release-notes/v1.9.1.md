# Gloam 1.9.1

Gamma 2.2 and 2.4 now preserve HDR highlights above SDR white at 100% brightness.

- Fixed a LUT shoulder that compressed highlight differences above SDR white, even when no dimming or color adjustment was active. With SDR white at 200 nits, the previous math mapped a 1,000-nit input to approximately 364 nits; gamma alone now leaves that input at 1,000 nits.
- Brightness adjustments now follow the requested dimming curve throughout HDR headroom without an additional compression shoulder.
- White-balance and measured-response adjustments fade from their correction at SDR white while retaining the HDR signal range. Constant-luminance night mode still accounts for the headroom consumed by boosted white.

This changes live HDR LUT output. Validation: all 1,351 tests pass and the strict Release build has zero warnings or errors. Twelve new regression cases failed before the fix and pass afterward, covering both gamma modes, measured-response LUTs, dimming, shadow-only adjustments, and 256-entry hardware-ramp conversion. These are computed signal values, not physical measurements; no fresh display/colorimeter validation was performed.
